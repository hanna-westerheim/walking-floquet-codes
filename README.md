# Walking Floquet code circuits for zero-overhead leakage reduction

Example circuits accompanying:

*Walking Floquet code circuits for zero-overhead leakage reduction*\
**Hanna Westerheim, Kaavya Sahay, and Shruti Puri**

See our arXiv manuscript for details.

`sample_circuits` contains example Stim circuits for the **swirling** and **sliding honeycomb Floquet code** circuits described in our paper. Each example is distance $6$, with $6$ full rounds of error correction (18 measurement subrounds). We apply uniform depolarizing noise with strength $p = 10^{-3}$.
